# Lloyd A. Vermont Sr. — Website

## Approved design baseline: V5 (November 16, 2026)

This repository is the home for the approved static website design for Lloyd A. Vermont Sr. and the book *Building Your Own Wealth Yourself*.

### Baseline design decisions
- Compact “Your wealth. Your future. Your legacy.” hero layout.
- Manual, one-at-a-time testimonial carousel with navigation arrows and dots.
- Expanded testimonials replace excerpts without repeating them or adding a divider.
- Approved book cover and unmodified supplied professional photographs.
- Warm cream, charcoal, and red palette inspired by the approved cover.

### Source package
The complete V5 source package has been prepared for import, including `index.html`, `styles.css`, `script.js`, `assets/`, `README.txt`, and `.nojekyll`.

**Import status:** The complete source package has not yet been committed. Do not enable GitHub Pages until all site files, including images, are present.

### GitHub Pages
Once the files are imported, this static website can be served from `main` / `(root)` using **Settings → Pages → Deploy from a branch**.

### Launch requirements
The newsletter is a demonstration and does not save email addresses. Verify testimonial permissions and names, book availability, disclosures, privacy policy, and content accuracy before a public launch.

The previous live website remains unchanged.
